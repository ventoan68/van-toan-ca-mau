Hướng dẫn cấu hình production

  1. Khai báo secrets trong Cloudflare Pages.
  2. Tạo password hash an toàn, không lưu mật khẩu plain text.
  3. API admin kiểm tra cookie HttpOnly trước khi cập nhật dữ liệu.
  4. Upload chỉ nhận JPG, JPEG, PNG, WebP và chuẩn hóa tên file.
  5. Thay ảnh minh họa bằng ảnh thật khi có dữ liệu đã kiểm chứng.
